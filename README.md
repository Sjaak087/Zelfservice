# Zelfservice – Firebase

Deze versie is bewust als één HTML-bestand gemaakt. Daardoor kan de pagina niet meer blijven hangen door ontbrekende css/js-bestanden bij het uploaden.

Gebruik per restaurant: `?restaurant=RESTAURANT_ID`

Producten, tafels, opmerkingen en restaurantinformatie worden live uit Firebase Realtime Database gelezen. Er is geen lokale instellingen- of productlijst.
